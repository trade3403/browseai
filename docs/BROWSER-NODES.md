# V0.4 浏览器节点与远程查看

开发顺序：1. 独立节点身份、心跳与容量；2. PostgreSQL 持久化与最小权限；3. 租户 profile 分配与独占运行；4. Linux Chromium/Xvfb 沙箱；5. 认证 noVNC 只读及独占人工控制；6. 多窗口、重连、故障恢复及双租户综合验收。

首批 1a 仅领域模型，心跳 30 秒失效，容量 1–256（协议上限而非实测性能），拒绝重复序号和错误代际，排空由可信控制面管理。后续必须独立认证、原子容量预留，不可将心跳自报当作可信租户授权。禁止公网直露 VNC/CDP，不保存聊天正文、键盘输入或录屏，不使用 OpenAI API；发送和登录由本人确认。CI 仅本地 mock，真实登录须本人验收。
