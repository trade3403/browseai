## 范围限制与后续责任

- V0.2 是认证与数据控制基础；authenticated 模式仅 loopback + 可信 HTTPS proxy，独立 auth/app DB role 与离线 account operator。默认 Compose/UI 仍 mock；生产部署、真实前端接入、会话/节点实时撤销、配置和权限安全审计尚未完成。
- RLS 是受信任服务设置事务租户上下文后的隔离，不防拥有 runtime DB role 的任意 SQL；身份变更与已开始请求之间仍存在并发边界，生产前需复核。
- 任务阶段按顺序运行，依赖只允许引用之前阶段；旧不完整计划不能进入 ready；计划暂不可直接编辑。Git 控制文件离线 schema 检查不证明远程 Git 事实。
- V0.3：每租户 GitHub App 安装授权、加密/短期 token、允许仓库真实 stable ID 与 branch 绑定、Webhook HMAC/去重/乱序、轮询及限流/分页、精确 head SHA 与 PR merge SHA 证明、必需 workflow/job 最新 attempt、拒绝取消/缺失/失败/歧义。当前没有真实 GitHub API adapter；用户配置 repo ID/验收字符串不是已验证证据。
